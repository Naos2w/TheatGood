# TheatGood

**台灣影廳 3D 座位視角預覽與個人觀影紀錄**（規劃中）

TheatGood 將整合台灣影城與影廳資料，提供 3D 影廳建模、座位第一人稱視角預覽、真實電影場次對照，以及個人觀影歷史紀錄。

- **核心功能**：選擇影廳與座位、預覽銀幕視角、記錄電影／日期／影城／影廳／座位。
- **不包含**：電影評分、心得、社群、即時售票與座位庫存。
- **預計技術**：Vue 3、Vite、TypeScript、Vuetify、TresJS / Three.js、Neon PostgreSQL、Drizzle、Vercel PWA。
