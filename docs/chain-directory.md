## 已停止營業的名稱不得混入

- 美麗新宏匯影城已於 **2025-12-22** 宣布停止營業，2026 年仍未見可靠證據顯示已恢復，因此**不列為可用分館**。舊版美麗新官網快取仍可能顯示宏匯，不能直接照舊資料匯入。參考[中央社以外之公開停業報導](https://www.mnews.tw/story/20251222nm020)與[2026-01-21 後續報導](https://www.nownews.com/news/6778318)。
- 不把分館「官網仍列示」理解為「今天正在營業」；臨時休館、設備維修、轉讓與分店名稱變動均需另外確認。

## 後續實作順序

1. **分館（此批已完成）**：品牌、地址、城市、來源與查證日期；搜尋與品牌篩選。地圖距離仍待核實各分館座標，此批未捏造任何距離數值。
2. **影廳（下一批）**：依官方廳別與設備說明建立影廳目錄，優先取得完整座號、走道與銀幕尺寸；若官方只有總席數，最多顯示資訊頁，不能生成假座號。
3. **真實場次**：研究四品牌是否提供允許外部使用的 API、資料授權與更新策略；官方網站能顯示場次，不等於授權第三方自動抓取與重發布。未取得條款確認前，先連官方場次頁而不聲稱已同步。
4. **3D／觀影紀錄**：以可驗證的廳別配對及模型版控建立 2D／3D；登入／觀影歷史延續既定 P2 項目。
5. **更多連鎖品牌**：國賓、in89、新光、喜樂時代等依同標準補入，先驗證停業與更名。

目前既有文化電影館的 5 座場館／9 個影廳、其中 2 間可預覽的 3D 模型仍保留，供真實座位圖引擎驗收，但商業影城優先。
