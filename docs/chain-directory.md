## 分館附近搜尋：40／40 場址位置已收錄

- **40／40 間連鎖分館**都有可追溯的場址座標，詳見 `src/features/cinemas/chain-positions.ts`。其中 39 筆來自 OpenStreetMap 的電影館節點或場館／商場中心點，1 筆來自[台南大遠百公園店同址場址座標](https://www.vrwalker.net/tw/print.php?serno=222&tbname=scenerys)。每筆保留來源網址及 `cinema` 或 `site` 精度標籤。
- 依品牌：威秀 **22／22**、秀泰 **15／15**、美麗華 **1／1**、美麗新 **2／2**。這是場館**定位覆蓋**，絕非已完成 40 間影城的 3D 座位圖。
- 新核對的四個來源：西門威秀同址前身絕色影城的 [OSM 節點](https://www.openstreetmap.org/node/2406854920)（漢中街52號，舊品牌標籤，不代表目前營運者）；北港秀泰的 [OSM 節點](https://www.openstreetmap.org/node/7197210913)；台中麗寶秀泰所在 Outlet Mall D 區的 [OSM 建物](https://www.openstreetmap.org/way/795510490)；台南大遠百威秀所在[公園路60號百貨場址](https://www.vrwalker.net/tw/print.php?serno=222&tbname=scenerys)。除北港秀泰的電影館點位外，其他三處均為**商場／同址場址估算**而非影廳入口。
- OSM 點位的授權與署名：**© OpenStreetMap contributors（ODbL）**，參考 [OpenStreetMap copyright](https://www.openstreetmap.org/copyright)。台南大遠百點位採獨立場館資料，不能將其視作 OSM 授權；網頁上可直接開啟個別來源。所有座標均由公開位置資料與影城官方地址交叉比對。
- 定位按鈕只在使用者點擊後要求瀏覽器位置權限；距離以既有的 Haversine 函式於裝置端計算，並保留未知座標的分館於後方；不呼叫外部距離、導航、地理編碼或即時地圖 API。
- 直線距離是**估算**，不是開車／步行距離，也不是營業狀態／售票狀態。OSM 資料和影城是否更名仍需持續核對。

## 後續實作順序

1. **分館（已達基本定位覆蓋）**：四大品牌 40／40 個分館已有名稱、地址、來源與場址點位；後續持續校驗非精確入口點位、搬遷、停業與營業日期。
2. **影廳（下一批）**：依官方廳別與設備說明建立影廳目錄，優先取得完整座號、走道與銀幕尺寸；若官方只有總席數，最多顯示資訊頁，不能生成假座號。
3. **真實場次**：研究四品牌是否提供允許外部使用的 API、資料授權與更新策略；官方網站能顯示場次，不等於授權第三方自動抓取與重發布。未取得條款確認前，先連官方場次頁而不聲稱已同步。
4. **3D／觀影紀錄**：以可驗證的廳別配對及模型版控建立 2D／3D；登入／觀影歷史延續既定 P2 項目。
5. **更多連鎖品牌**：國賓、in89、新光、喜樂時代等依同標準補入，先驗證停業與更名。

目前既有文化電影館的 5 座場館／9 個影廳、其中 2 間可預覽的 3D 模型仍保留，供真實座位圖引擎驗收，但商業影城優先。
