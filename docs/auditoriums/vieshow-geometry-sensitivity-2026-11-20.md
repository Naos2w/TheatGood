# 威秀／MUVIE 幾何來源與視角敏感度稽核（2026-11-20）

> 這是 **P1 演算法與來源可靠度驗證**，不是完成實體影廳測量、座位推薦或正式上線驗收。現有 2D／3D 顯示方式與目前公開的來源快照不改動。

## 範圍

- 維持原有 **22 個分館、222 種已保存官方公開座位格線**；只使用現有 `loadVieShowArchiveForCinema` 所驗證的廳別、座號、格線位置與採樣來源。
- 對每一份格線，從**實際存在的座號**選取前排中央、中排中央、後排中央、左側邊緣、右側邊緣，計算虛擬銀幕距離、水平／垂直視角及左右偏移。不同位置若剛好是同一座位，允許重複取樣，不造新座位。
- 以同一套 `deriveVieShowPreviewGeometry` 和 `calculateSightline`，對五種有名稱的**說明性假設情境**比較變化，避免不同程式各算各的。使用 `auditVieShowHallGeometry(cinemaSlug, layout)` 取得結構化結果。
- 每份結果含目前採樣日期、原始官方格線來源、公告席數比對狀態、銀幕尺寸來源級別及該銀幕資料是否僅靠「容量交叉比對」對應實體廳。**無直接證據的廳號映射一律不升級為實測／已證實**。

## 資料可信度與特例

1. **座號與相對格線**：來自威秀公開售票座位頁快照；公告席數對照仍有 **18 種不同**，保留原差異，不自行補位。
2. **MUVIE 台北松仁 TITAN 的 22 × 12m**：銀幕規格取自威秀官方，但與「第 6 廳／391 一般座號」的對應是容量交叉比對，**沒有固定實體廳的官方施工圖**。來源：<https://www.vscinemas.com.tw/about/>。
3. **板橋大遠百 IMAX 的 21.33 × 11.46m**：取自尚未得到業者直接確認的第三方資料，廳號仍以席數比對，不得稱為官方實測。參考：<https://reelax.app/halls>。
4. **其他廳**：未知銀幕寬高使用明確標示的概念估算；未取得有比例尺的物理座位平面圖，因此水平方向公尺格距、銀幕距離、每排高度、坡度、銀幕底緣與牆面仍未量測。
5. **有官方銀幕寬度，也不代表座位區寬度已知**。目前「銀幕寬／座位區寬」仍可調，不能因模型使用公尺就宣稱真實 1:1 POV。

## 檢查與下一步

執行 `npx vitest run src/features/viewer/vieshow-geometry-audit.test.ts`，核對 222 個來源模型、所有取樣座號與數學結果均有效，並保留官方／第三方尺寸及容量差異標記。

真正的下一個 **實體校準門檻**是取得能對應到相同**永久廳號**的合法來源、銀幕正面寬高、首排距離、排距／坡度及輪椅席安排；不足時仍維持估算級別，不更改模型版本及已保存的個人足跡。跨裝置私人觀影紀錄為獨立 P2 工作，**不以研究資料已完成為前置條件**。
