# 小影格（國家電影及視聽文化中心）— 資料來源與建模紀錄

> Model ID: `tfai-small` / Schema version: 1 / 查證日期：2026-11-15

## 官方可確認

來源：[國家電影及視聽文化中心場館設備資料手冊](https://www.tfai.org.tw/rsrc/tfai_document/%E5%9C%8B%E5%AE%B6%E9%9B%BB%E5%BD%B1%E5%8F%8A%E8%A6%96%E8%81%BD%E6%96%87%E5%8C%96%E4%B8%AD%E5%BF%83%E8%A8%AD%E5%82%99%E8%B3%87%E6%96%99%E6%89%8B%E5%86%8A.pdf)，頁 2（設備規格）與頁 4（小影格座位圖）。

- 位置：新北市新莊區文藝路 2 號。
- 銀幕：**8.88 × 4.80 公尺**（實際畫布比例約 1.85:1）。
- 座位：**52 席（40 固定、12 活動），另有 2 席輪椅席**。
- 座號與排數：官方座位圖 A–F 排。以觀眾面向銀幕時的左到右為順序，模型保留官方圖上的缺號，不自行補齊。

| 排   | 依官方圖整理的座號             |   席數 |
| ---- | ------------------------------ | -----: |
| A    | 1, 2, 3, 4, 5, 7, 8, 9, 10, 11 |     10 |
| B    | 1–11                           |     11 |
| C    | 1, 2, 5, 6, 7                  |      5 |
| D    | 1, 2, 5, 6, 7, 8, 9, 10        |      8 |
| E    | 1, 2, 5, 6, 7, 8, 9, 10        |      8 |
| F    | 1–10                           |     10 |
| 合計 |                                | **52** |

座號與官方設備手冊的座位圖對照整理；部分座位屬活動席，實際售票、座椅配置與無障礙席使用方式仍需以影城最新資訊為準。

## 仍為估算，未經場館實測

`tfai-small.json` 的以下數值是為了產生可操作的 3D 模型所做的示意估算，**不可作為真實視角精度的證明**：

- 銀幕底緣高度（0.8 m）、銀幕立面與曲率（目前以平面近似）。
- 前排與銀幕距離、各排排距、椅距、缺號座位間的實際空隙。
- 各排高差、影廳地板、側牆與後牆的位置。
- 座椅寬度、視點高度（1.15 m）和座位觀看角度。

App 使用相同的模型座位 X 座標產生 2D 座位圖與 3D 椅子，並將水平／垂直視角與距離標為「估算」。未實際放入輪椅席的 3D 模型；目前 52 個選位控制只涵蓋手冊統計的非輪椅席。

## 著作權、維護與後續校準

- 僅引用官方尺寸、座位編號等事實資料並提供來源連結；**未將官方座位圖圖片、原始 PDF 或場館照片複製進 Repo**。
- 設備手冊的公開查閱不等於取得圖片、照片或完整場館圖面的重製授權；若未來需要直接展示，應先向權利人確認。
- 目前手冊並非即時售票座位圖，可能與最新影廳配置不同；上線前應核對現況。
- 下一步以影城提供的實測排距／坡度、現場丈量資料或具合法使用權的測量成果逐項替換估算值，並更新模型版本與可信度。
