# TheatGood｜2026-11-23 連鎖影廳來源補件與現行官方席數複核

> 這是研究／資料正確性 checkpoint，**不是新增 3D 實體影廳**。不從席數、座型重複次數或暫時場次連結推斷永久廳號，也不蒐集票況、會員帳密或進行訂票。

## 1. 既有 3D 基線不變

- **394 份**來源支持的連鎖影廳 3D 預覽：威秀／MUVIE 公開座圖 **222**、秀泰 MSI 私人已核實 **159**、美麗新官方公開座型 **13**。
- 秀泰為 **159／159 個「抽樣」廳號**，不等於全部實體廳的官方普查；私人下載、座位格線與研究快照仍只有 MSI 授權 Tailscale 可見，不加入公開資產。
- 其餘 **6 個院線／27 個分館**仍待完整座號與走道格線：國賓 9、in89 6、百老匯 2、喜樂時代 4、新光 5、美麗華 1；不能拿公布容量推出可信 3D。已有的 **222 筆**其他院線公開席數研究不等於 222 張座位圖。

## 4. 國賓與 in89 下一步

- [國賓官方訂票選場次](https://booking.ambassador.com.tw/frontend/booking-selectscreening2.html)公開列出「場次→票種→劃位→付款」，[現行影城設施資訊](https://www.ambassador.com.tw/home/theater_intro_b1)則是逐廳席數；可以確認官方來源途徑，但尚無已核對完整座位格線。該訂票網站另有帶 **2015** 年歷史示例的座位頁，不能當 2026 年座圖。<br>
- [in89 官方訂票說明](https://www.in89cinemax.com/boomboom/question.aspx)顯示需依場次進入訂票流程、會員辦理選位。先前已保存的六館 **2022** 年圖片只包含席數／局部無障礙資訊，還不是當期完整座號格線。
- 必須取得可合法查核的**現行官方逐排座號與走道**，保存分館、確切廳號、來源日期／類型與變動版本，再驗證格線後才可建模。現階段**不猜測私有 API、不繞過登入、不產生購票訂單**。

## 發版邊界

這輪對現有 3D 幾何、座圖、播放器及已定版 UI **沒有任何修改**。新的私人來源不複製到 Git／Vercel。僅將即時核對的**美麗華公開席數**與來源日期更正，使用原有測試保證不產生不存在的座位模型；待整套測試通過再經 `develop → staging` 的 UAT 流程。
