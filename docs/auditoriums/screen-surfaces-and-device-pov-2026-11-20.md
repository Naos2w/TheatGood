# 電影銀幕表面、特殊廳格式與跨裝置眼睛視角稽核（2026-11-20）

> 本文件整理**銀幕表面材料**、**影廳設備格式**、**電影放映格式**、**3D 建築幾何**之間的差異。不可把它們混為一談。台灣各影廳若沒有直接來源證明材質、曲率、傾角，預設仍為**不明／未校準**，不自動填入「銀幕實測」。

## 2026-11-20 使用者實際截圖回饋後：選座視角修正

本研究原始 PR #49 曾把 **80° 水平 FOV＋相機水平朝前**設為預設，使用者在板橋大遠百 IMAX 第 6 廳 A11、N31 的桌面及手機／平板截圖中發現：**部分座位的大部分畫面在銀幕下方，無法直觀看到銀幕位置是否合適**。這是虛擬相機「自然平視」的預設造成的，**不能拿此裁切畫面判斷那個座位好壞**。

修正以使用者選座目標為準：

1. **預設座位 POV 是眼睛位置看向銀幕中央，恢復原先 65° 水平鏡頭預設**；沒有推移眼睛、座位、銀幕、模型幾何、實際座號，也不自動重構銀幕大小。
2. 「水平參考視角」仍可在資訊面板中手動切換，但不再是預設；重設視角回到銀幕中心。其他同廳座位維持同一鏡頭基準，不能為了讓每座的銀幕一樣大而個別縮放畫面。
3. 另以模型計算「看向銀幕中心需垂直／水平旋轉的估算角度」：**正值為向上／向右**、負值為向下／向左，讓主畫面即使已對準銀幕，仍可比較不同排的仰角和左右偏移。板橋 A11 與 N31 的模型角度差異有回歸測試，但這些角度取決於尚未實測的排距、坡度和銀幕位置，不能當成現場量測。
4. 保留 PR #49 原本的**不同裝置畫布比例換算**，直式螢幕仍限制極端魚眼廣角；手機直式無法保證同時展示全部 IMAX 寬度，應切橫式或拖曳環視。並非使用了真正人眼校準的 FOV。

**隔離 Chromium 開發預覽檢查：** 板橋第六廳 A11 在桌面寬度 914px 時，資訊面板預設顯示「銀幕中心（預設）」、模型估算垂直 **+43.0°**、水平 **+37.2°**；N31 在手機模擬 393×852 時，預設同為銀幕中心、估算垂直 **+9.1°**、水平 **−30.2°**。手機手動選擇「水平參考視角」再按「重設視角」，確實回到銀幕中心。測試預覽端口與隔離瀏覽器已關閉。**這是基於尚未校準的幾何假設，不是現場實測角度。**

以下第 3 節同時記錄初版 PR #49 的技術演變；本節的修正**優先於**初版 80°／平視預設。

## 1. 同一家影城的 2D、3D、4D 銀幕真的一樣嗎？

- **2D** 是放映方式，不代表銀幕表面只能用哪種材料。標準影廳常用白色／高反射布幕；增益、穿孔、亮度均勻性由特定設備決定。
- **偏光式 3D（例如 RealD）** 仰賴保留偏振的表面；傳統銀幕或新世代 RealD Precision White／Harkness Clarus XC 可同時用於 2D、3D，卻不等同於一般消偏振白幕。3D 不是把銀幕加厚或加彎，RealD 官方提及銀幕去偏振會造成立體影像鬼影；Harkness 說明其材質可在同一表面兼顧 2D 和 3D。引用：
  - RealD：<https://reald.com/better3d/>
  - Harkness Clarus XC：<https://www.harkness-screens.com/clarus-xc>
  - Harkness × RealD Precision White：<https://www.harkness-screens.com/precision-white-screens-by-reald-and-harkness-screens>
- **IMAX / IMAX 3D** 是一整套影廳與放映系統，不代表每部片都 3D，更不代表每座 IMAX 銀幕有相同弧度。IMAX 官方 **2003 年度**財務技術資料對當年的 GT／SR／MPX 影廳描述的是平面或小幅曲率／傾角、可放 2D／3D；大幅曲面與傾角另屬圓頂影院類別，該分類是當年的歷史系統，不足以推論所有 2026 新裝影廳。參考：<https://investors.imax.com/static-files/da420640-def1-4f57-8fd7-d5eaf43913b4>。**不可用單一半徑套所有台灣 IMAX。**
- **4DX、MX4D、D-BOX** 首要區別為動態座椅／環境效果；4DX 仍可標示 4DX 或 4DX 3D，同廳不同放映格式不必換一塊物理銀幕。威秀官方定義：<https://www.vscinemas.com.tw/vsTicketing/ticketing/booking.aspx>（實際帶場次參數的票務頁亦有一致的 IMAX／4DX 與 3D 定義）。**4DX 不等於曲面幕。**
- **ScreenX** 是正面主銀幕與左右側牆的獨立延伸投影，標稱 270° 是環繞體驗，不是一整片 270° 的無縫彎布。**ULTRA 4DX** 把這種側投影與 4DX 特效合併。CJ 原廠：<https://newsroom.cj.net/screenx-transforms-entertainment-experience>、<https://newsroom.cj.net/cj-4dplex-and-showtime-group-unveil-cutting-edge-ultra-4dx-and-screenx-theaters-at-taiwans-flagship-taipei-dome/>；中央社採訪：<https://www.cna.com.tw/culture/article/20250617w004>。
- **LG Miraclass Cinema LED** 是自發光 LED 模組牆，沒有傳統前端投影布幕，部分型號亦支援 3D（廠商設備需配主動式眼鏡），不可當作普通 2D 布幕或 ScreenX。LG 官方：<https://www.lg.com/global/newsroom/b2b/product-and-solutions/lg-cinema-led-screen-lg-miraclass-brings-immersive-viewing-experience-to-theaters/>。

## 3. TheatGood 本輪真的修改了什麼

改動僅限**虛擬相機**，並不更動原有的 2D 官方座號、3D 座位位置、模型版本與來源化的銀幕尺寸，也**尚未將特定影廳改成曲面幕**：

1. 舊版威秀 3D 預設水平 FOV **65°** 使大螢幕在桌面上幾乎撐滿高度，現在採較寬的 **80° 虛擬相機預設**，屬觀看方式調整，並非假設人眼是 80° 鏡頭。
2. 座位 POV 預設朝銀幕中央的**水平方向**較平視，不再強制垂直瞄準銀幕中心。使用者可切換「自然平視／對準銀幕中心」；兩種模式的**眼睛 Y 高度完全相同**，也保留拖曳手勢抬頭。
3. `responsiveCinemaFov` 依實際 CSS 畫布寬高比調整 Three.js **垂直** FOV；手機／平板直式不再暴增至 110–130° 的誇張廣角，而以最多 78° 的鏡頭保留中央視野。直式畫面不可能在維持同樣物理角度時完整裝入寬 IMAX，**左右可能被裁切**，可以拖曳、旋轉為橫式或切換全廳概覽。
4. 超寬桌面畫布使用不小於約 42° 的垂直 FOV 以避免相機在狹長視窗將畫面上下塞滿；一般桌面／橫向平板保留正常水平 FOV 換算，鏡頭不會因像素大小或 DPR 改變座位比例。
5. 手機、平板、桌面、超寬畫面均加入純函式檢查；板橋第 6 廳 N09 比對實際座號與相機方向，確保切換視線**不移動眼睛／銀幕／座位**。

**本機瀏覽器視覺檢查（隔離 Chromium 開發預覽）：** 已打開板橋大遠百第六廳 N09，檢查 393×852（手機直式）、844×390（手機橫式）、820×1180（平板直式）、1440×900（桌面）尺寸下的座位控制列與資訊面板；模式切換後，介面由「自然平視」正確切換到「對準銀幕中心」。資訊面板將視線切換放在上方，避免受到有限高度和卷軸遮蔽。僅屬 Chromium viewport 模擬；未測得實際手機／平板裝置的物理 FOV，也未保證原生 Safari／Android 的 WebGL 畫質完全相同。

**誠實限制：** 所有 FOV 都是可閱讀的**模擬鏡頭選擇**，手機物理尺寸、持機距離、眼球轉動、使用者個別視力及眼鏡未量測，並非對個人眼睛 1:1 校準；IMAX 3D 的偏光與曲率、ScreenX 多面影像、4DX 動態座椅另需逐廳來源與獨立驗證，不能因這次 FOV 通過測試便打勾。
