# TheatGood｜秀泰 102 個公開廳號缺漏：定向蒐集 v0.1.5

> 2026-11-20 基準：15 間秀泰分館，原始公開電影場次出現過 **159 個分館＋廳號**，57 個有已核實的座位格線，仍缺 **102 個**。159 是場次樣本，不等於目前實際永久廳總數；未排片的廳未必能從當期網站取得座位格線。

## 新的官方觀影視角功能

2026-11-17 秀泰宣布官網購票流程提供「模擬座位視角」與聲音／部分動感體驗。來源：[NOWnews](https://www.nownews.com/news/6893004)、[JUKSY](https://chill.juksy.com/article/154874)。這個功能**不代表所有廳格線公開可下載，也不授權 TheatGood 複製其 3D 模型**，但可作為日後逐廳核對時的官方參考。

## 定向流程

- 既有 TheatGood 秀泰 MV3 擴充功能提升至 **v0.1.5**，保留只限秀泰官方網域、無 Cookie／debugger／webRequest 權限，永不選座、購票、付款、讀取密碼或繞過登入／驗證。
- 增加**只開指定缺漏廳號**的模式。缺漏列表由 MSI 上既有來源快照、合法下載和公開廳名 census 即時算出；本機一次性請求只傳「本館缺的廳號」，且擴充功能會再驗證每個廳號都在該館 census。
- 普通工具列按鈕保留原本一輪最多三部電影的研究行為；只有明確發送一次性定向指令才會檢查從 `StartMovie` 起的至多 **8 張電影卡**，每部只開至多 **4 個不同缺漏廳**的唯讀座圖，總掃描時間維持 **75 秒**。已核對的廳、其他館的場次都不會開座位預覽。
- 此輪沒有包含某缺漏廳時，回報未取得而非假造其座號。後續可用 `StartMovie 8`、`16` 分段查看**不同公開電影卡**；嚴禁不必要的連續重試或網站負載。
- 所有原始座位格線仍只保存在 MSI `Downloads/TheatGood`，網頁沒有新增秀泰正式 3D，且 `approvedForPublicUI=false` 維持不變。上架另須業者資料使用許可、逐廳來源核實與 UAT。

## 重跑方式

`pwsh -NoProfile -File scripts/research_trigger_showtime_targeted_once.ps1 -CinemaSlug showtime-yunlin-beigang -StartMovie 0 -DryRun`

檢查缺口來源、已登入專用 Chrome v0.1.5 正常、研究單次安全限制，再移除 `-DryRun` 發出一次性唯讀請求。

## 驗證與仍缺的資料

- 合成 VM：未登入拒絕、外館與未列入 census 廳拒絕、已完成廳的座位視窗不開啟、只開缺漏的真實預覽、未見目標時不輸出假資料。
- 合成 Chromium：模擬登入、正常／定向單次請求、目標不存在時拒絕、沒有碰實際使用者 Chrome／帳戶。
- 將實際每次下載用本地 metadata 對照與 SHA 進行來源核驗，絕不將會員 JSON 放進 Git。

逐館缺口參見 [2026-11-20 秀泰來源表](showtime-source-coverage-2026-11-20.md) 及 [metadata JSON](showtime-hall-coverage-2026-11-20.json)。其餘無當期場次、需官方直接提供資料或授權存取的廳仍需保留未完成，不能承諾已取得全部 102 份。
