# 威秀／MUVIE 全台公開座位圖採樣與驗證（2026-11-16）

**目標：**蒐集真實影廳的排別、座號、座位格線、走道缺口與銀幕方向，提供 TheatGood 的 2D 參考座位圖；不把電影場次、售票、訂位或空位庫存作為產品核心。

## 來源與保存方式

- [威秀官方場次／售票入口](https://www.vscinemas.com.tw/vsTicketing/ticketing/ticket.aspx)：選擇分館與當前公開電影，再開啟場次旁的座位預覽。座位連結格式 `https://sales.vscinemas.com.tw/VoucherTicketing/SessionSeats.aspx?CinemaCode=...&txtSessionId=...`。只記錄 `GridViewSessionSeats` 的座號、表格列／欄及輪椅圖示，保存廳號、原始網址與採樣日期。
- [威秀 2026/05/21 官方逐廳座位容量表](https://www.vscinemas.com.tw/upload/biz/biz_20260528001.pdf)：提供 229 筆數字廳容量對照，並不保證是 2026/11 所有影廳的最新實際配置。座位表可變更，場次連結可能過期。
- 部分直接 HTTP 存取會回傳 403；資料是透過官方網站正常的公開座位預覽採集，沒有登入、購票、繞過會員限制，亦不保存售出／可售、價格、個資或官方原始影像。
- 31 份研究批次紀錄為 `src/features/cinemas/data/vieshow-collection-*.json`；`scripts/build-vieshow-snapshot-archive.ts` 去重與驗證後產生 22 份 `vieshow-snapshots-2026-11-16/<分館>.json` 和覆蓋率、差異稽核。各館頁面按需載入自己的 JSON。

## 可證實的完成度

- **22 個威秀／MUVIE 分館**皆有公開座位配置，去重共 **222 種以分館＋廳號／廳名識別的配置**。
- 以官方 2026/05 的 **229 筆數字廳**為分母，已有 **205 筆廳號對應座位表**，**24 筆無直接對應**。
- **187 種**編號座位數與官方容量完全一致；**18 種**不一致；**17 種**沒有可直接對應的官方容量（含英文字母廳、GC 特殊廳與新數字廳）。
- 來源衝突檢查：**0 筆同一廳號、同日不同格線的衝突**。這不代表當前影廳配置永遠不變。

## 功能界線和未來擴充

- 全部採集影廳在 TheatGood 對應分館頁提供原創 SVG **2D 參考圖**；保留真實座號、相對列欄及走道缺口。純數字座號顯示視覺列索引，不擅自改成 A／B 排。
- 沒有座位圖的官方廳號顯示未完成；席數不符則顯示警告。原始場次連結到期不影響已保存的靜態 2D 圖。
- **未量測的銀幕寬高、排距、首排距離、坡度及遮蔽，不當成真實公尺**；目前不把這些 CSS 格線直接轉為精準 3D 或自動綁定個人觀影足跡。
- 對剩餘 24 筆廳號在新場次推出時再核對，優先為信義 13、巨城 3／6／7、台中大遠百 2／7，以及花蓮、南紡、GC 的廳別建立正式對照。
