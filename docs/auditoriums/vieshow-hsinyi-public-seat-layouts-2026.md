# 信義威秀官方場次座位圖採樣（2026-11-16）

這份資料是 TheatGood 的**逐廳座號／座位格線參考圖**，不是售票庫存、官方圖片，也不是已量測的 3D 影廳。全部來自使用瀏覽器唯讀開啟的威秀公開場次「座位圖」連結，不需要登入、選擇票種或購買。

## 來源與採集方式

1. 從[威秀官方電影場次](https://www.vscinemas.com.tw/vsTicketing/ticketing/ticket.aspx?cinema=1%7CTP)選擇台北信義威秀影城與電影，找到場次右方的**座位圖圖示**，在公開頁開啟 `/VoucherTicketing/SessionSeats.aspx?CinemaCode=1&txtSessionId=...`。
2. 頁面標題提供**台北信義威秀 + 永久第幾廳**，而非只提供廳型。將此廳號和[威秀 2026/05/21 官方席數表](https://www.vscinemas.com.tw/upload/biz/biz_20260528001.pdf)交叉確認。
3. 從 `table#GridViewSessionSeats` 依序讀取每一個 `tr`／`td`，有座號的元素使用 `title="A01"` 等屬性；`Null.png` 是格線缺口；`img[alt="輪椅位"]` 是輪椅位置。格線以 **1 起始的 row／column** 儲存。
4. 保存**可查證的座號、格線位置、另列的輪椅位置、採樣場次網址與時間**，不保存「已售出／可售」、會員、訂票、票價、任何個資、原始網頁 HTML 或原始圖片。
5. 由 TheatGood 原創 SVG 重畫 2D 參考圖。其他廳若需擴充，須再次由官方公開場次導航到座位圖，確認「實體廳號＋座位數」後，才新增快照與測試。

直接開深連結時曾出現 HTTP 403 或返回首頁；從**官方目前列出的電影場次頁點座位圖圖示**可正常開啟。這些來源連結只作查證，不當作永久 API，也不依賴任何會員認證或繞過網站存取控制。

## 尚未證實與不開放的功能

- 銀幕實際寬高、弧度、距離首排的長度、排距、座椅眼高、坡度與視線遮蔽都**未量測**。
- 格線欄距只能表示缺口／相對位置，**不能換算真實公尺**；目前不建立這兩廳的精確 3D 或自動將座位貼回個人觀影足跡。
- 只有第 6／11 廳是這次採樣且核實的當期公開售票圖；第 12 廳另有獨立的 2026 影展參考模型，不能混在同一份當期配置。
- 其他信義威秀廳別與其他影城的逐廳座位配置仍待依相同方法採樣。遇到無公開存取座位圖、廳號不明或座數不一致，應保留未知，不猜測排別。
- 場次 ID 與訂票連結會更動；同一廳改裝後應保留歷史快照與來源日期，而非靜默覆寫舊觀影座位資料。
