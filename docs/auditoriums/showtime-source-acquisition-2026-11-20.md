**本次範圍未收完：**台中文心略過 29 個來源分館不符的場次、遇到 1 次逾時，並在安全時間上限停止；大巨蛋略過 27 個不符合分館的場次，在安全時間上限停止。所有略過項目都不是座位配置。因為受單輪電影數、廳數與時間限制，**未收錄的其他影廳不能標示「不存在」**；再次掃描也可能遇到相同場次，不應盲目重跑。

**累計狀態必須分清：**原先已做原始下載校驗的 **23 份／2,489 座／9 分館**，加上本輪新增 **6 份同卡來源觀察／944 個座號／2 分館**，形成 **29 份來源觀察／3,433 個座號總和／11 分館**，但其中部分內容與舊的 46 份未核定格線相同，這不是去重後的永久影廳或真實全館容量。**新 JSON 尚未匯入既有研究快照、更未上架公開 Dev 3D；原研究檔與 manifest 仍維持 `approvedForPublicUI=false`。**要導入正式路由，仍需來源權利判斷、逐廳身分與驗收。

## 缺口與需要使用者協助的步驟

**2026-11-20 初次稽核時**，MSI 秀泰專用 Chrome 尚未執行；**同日晚間使用者已開啟專用 Chrome 並成功完成台中文心與大巨蛋兩輪唯讀掃描**（新增檔案及核對結果見本頁第一節）。後續仍只能在使用者正常登入的官方會員頁、由單張場次卡核對來源，不能由公開節目頁生成完整格線。**不繞過登入、反機器人驗證、隱藏 API，不讀取 Cookie 或密碼，不選座或結帳。**

使用者在 MSI 前可執行既有 `scripts/open-showtime-login.cmd`，於秀泰官方頁自行登入。專用 Chrome 是獨立設定檔；勿改動一般 Chrome／Edge、機票雷達的瀏覽器。若擴充功能已安裝，於 `chrome://extensions` 檢查「TheatGood｜秀泰座位研究（唯讀）」並視需要重新載入。若正常登入或網站驗證失敗應停止，不強制重試。正式讀取時先核對台中文心與大巨蛋的來源歸屬。
