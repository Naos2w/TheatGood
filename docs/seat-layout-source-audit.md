## 3D 模型發布條件

1. **來源需具體到「分館＋影廳＋版本／查證日期」**。網友座位圖、舊活動 PDF、訂票畫面需要對照最新營運資料。非來源清楚的圖不可直接當成現有配置。
2. **逐排座號清單、缺號及主要走道**須與影廳官方容量合理相符，並明確記載輪椅席與特殊席位是否包含在總數中；不得靠數學平均分配席數推算。
3. **銀幕大小與位置**須引用官方量測或明確標示估算。若某項可估算的幾何參數缺來源（座距、排距、階梯坡度、眼高、曲面半徑），逐項標示而非宣稱「精確實測」。
4. 同一 JSON 模型生成 2D／3D；前、中、後排與左右邊緣檢查座號和視角一致；更新模型時保留舊版並避免把舊觀影足跡誤投影到新座位。
5. 不複製官方座位圖影像到專案資產；僅在來源合法且資料清楚時，重建結構化的座號事實。若需重用原始圖片，須另確認圖像權利。

## 已完成的核心使用者體驗

既有兩間真實影廳（小影格、光點台北）可用同一模型提供 2D／3D。個人歷史紀錄按目前模型版本核對後在**原座位圖**亮出坐過的位置，允許統計多次坐同一位置、點選座位查看對應電影及返回視角。若只有文字座號／舊模型版本，**不顯示虛構圖點**。

3D 相機採用可調水平視野角，並依畫面長寬比換算垂直 FOV；它是虛擬鏡頭投影校正，並非使用者眼睛／螢幕視距的實測 1:1 校準。
